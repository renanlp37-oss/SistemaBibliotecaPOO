SISTEMA DE EMPRESTIMOS DE UMA BIBLIOTECA COMUNITARIA
Projeto Java compatível com Apache NetBeans (Maven).

COMO ABRIR NO NETBEANS
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o Apache NetBeans.
3. Vá em File (Arquivo) > Open Project (Abrir Projeto).
4. Selecione a pasta SistemaBibliotecaPOO que contém o arquivo pom.xml.
5. Aguarde o NetBeans carregar o projeto e execute a classe principal biblioteca.Aplicacao
   usando Run Project (F6) ou clique com o botão direito no projeto e escolha Run.

CLASSE PRINCIPAL
biblioteca.Aplicacao

CLASSES
Leitor.java, Livro.java, ItemEmprestimo.java, Emprestimo.java, Biblioteca.java e Aplicacao.java.

FUNCIONALIDADES
Cadastro, consulta, listagem, atualização e remoção de leitores e livros;
registro e listagem de empréstimos; registro de devolução; validação de códigos,
campos obrigatórios, disponibilidade de livros e empréstimos em aberto.

IMPORTANTE
Os dados ficam somente na memória durante a execução e são apagados quando o programa fecha.
Confira o código e pratique executar cada opção para conseguir explicar o funcionamento
do trabalho ao professor.
